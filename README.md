# RemoteOps - Remote Execution Tool
Student ID: IT24101098
Module: Data Communication and Wireless Networks
Environment: CentOS 10
Port: 9410

## Overview
RemoteOps is a socket-based client-server application written in C. It allows a Controller to establish a secure TCP connection with an Agent, send system shell commands, and retrieve command execution results.

## Compilation
make -f Makefile_098

## Usage
1. Run the Agent: ./agent_098
2. Run the Controller in a separate terminal: ./controller_098
